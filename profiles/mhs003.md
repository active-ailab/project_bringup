# mhs003

板型：`HMI_BOARD_MHS003_` + 产品名大写。路径相对 HMOS 根。`module.mk` 不改。

前提：`products/<base>` 与 `Config.in` 中 BASE 板型均存在。

## 复制

| 源 | 目标 |
|---|---|
| `platform/board/mhs003/products/<base>/` | `products/<new>/`（含 sensorhub） |
| `configs/mhs003/` 成词匹配文件 | 文件名 base→new |
| `.repo/manifests/` 成词匹配 `*.xml` | 文件名与内容中产品 token / `releases/<base>/` → NEW |
| sport 分产品头（list/settings/type/special/rt_attr 等，有则拷） | `*_<new>.h` |
| `components/hal/sensor/config/<base>_sensor_config.json` | `<new>_…` |
| `framework/gnssAdapter/**/gnss_<base>_config.json` | `gnss_<new>_…` |
| `platform/board/mhs003/ramdump/**/<base>/` | `…/<new>/`（文件名中产品 token 同步改） |
| `ui/**/config.json` 的 `projects.<base>` | 增加 `projects.<new>`（深拷贝） |

defconfig 定向替换：板型、`HMI_PRODUCT_CUSTOMIZE_DIR`、`BX_CHIP_RTL8763EFL_BIN_FOLDER`、`mhs003_<base>_sku`、`BUILD_PROJECT_PATH_NAME`（值=base 时）、`ramdump_<base>@`。

## 挂接

| 范围 | 做法 |
|---|---|
| `Config.in` | 新板型 + default |
| sport dispatcher / `sport_rt_attr_auto.c` | `#elif (NEW)` → 新头文件 |
| `components/hal/module.mk`、gnss `module.mk` | 复制 BASE 的 `ifeq` 配置块到 NEW |
| NFC / logo / applist / 其它含 BASE 板型处 | `BASE \|\| NEW` |

## 校验

`products/<new>`、`mhs003_<new>_defconfig`、`Config.in` 含新板型。

## Phase2（流程同 SKILL；此处只写落点/格式）

**前提**：Phase1 已完成。数据输入：[项目Bringup硬件配置模板](https://zepp.feishu.cn/wiki/OR4Tw7BNRi96gEkmSNUcvzstnMc)（必填：器件类型+型号+SKILL配置；供别/备注选填）。**总流程与其它平台相同**，见 [SKILL.md](../SKILL.md)。GPIO：`scripts/phase2_gpio_diff.py --explain`。

| 项 | 起点（以仓库实文件为准） |
|---|---|
| GPIO | `platform/board/mhs003/products/<new>/board_pinmux_private.c`、`include/board_pinmux.h`、`include/board_config.h`（多为 PAxx） |
| 器件 / defconfig | `configs/mhs003/*_<new>_*` |

**器件**：不按型号表映射。`SKILL配置=是` 时按 [SKILL.md](../SKILL.md)「器件落码」在本仓库搜索 NEW 型号的现有写法；同型号或 `SKILL配置≠是` 不改。

### GPIO

- 只处理 BASE≠NEW；确认后按仓库实文件适配（含 `board_config.h` 总线开关）。
- overlay 仅允许在 NEW 列与已有产品 pinmux **逐脚比对**命中之后；禁止用产品名猜测对照源；覆盖后仍按表差补漏。
